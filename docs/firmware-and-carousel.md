# 组件轮播与固件升级

## 只轮换一个区域

在画布编辑器点击“组件轮播”，或选中原有 HA 实体后点击“改为组件轮播”。添加实体、填写屏幕名称，使用上下箭头排序。留空名称时跟随 HA 的实体名称；单位留空时跟随各实体。眼睛按钮只预览指定项目，“恢复自动预览”回到按时间切换。

建议区域为 96×32 像素。每项停留时间以 1 分钟调整，最多 8 项。点击“保存页面”后数值快照和所有项目一起下发，MCU 离线也能轮播；HA 新读数按屏幕的更新间隔合并下发。unknown / unavailable 显示缺失值，不伪造温度。

需要保持整张画布固定时，关闭“整页轮播”。已有其他画布会保留。组件轮播也能保存为模板，复用到其他墨水屏。动态区域不能重叠，最多四个（包括时钟、日期、倒计时与屏幕温度），全部显示数据总共不超过 16KB。

小变化使用快速刷新，大变化、首次、手动或整点使用全刷。当前 A41 控制器在每次刷新时仍需要写完整 RAM，以避免控制器断电丢失 RAM 导致花屏；这里减少的是画面变化和全刷波形次数。实际寿命与续航仍需长期测量。

## 每块屏幕的内容同步间隔

在该屏幕的“屏幕设置与同步间隔”中填写秒数并保存，也可以从“设备状态”进入。最低 30 秒，最高 86400 秒，支持 45、90 等任意整数秒；默认 300 秒。每块屏幕独立保存，修改一块不会修改其他屏幕。

HA 实体通过 WebSocket接收最新读数，按该屏幕的间隔合并发送；趋势图即使实体值不变也会按该间隔重新读取 HA Recorder 历史，继续推进时间窗口。实际发送前比较显示包，内容相同就不发送、不刷新；更新失败保留待更新状态，自动重试。设备状态中分别显示最近内容检查和最近确认刷新。

这个设置控制 HA 内容同步。时钟由 MCU 每分钟计时更新，页面和组件轮播使用各自的分钟间隔；重连和至少每 24 小时对时，内容传输也附带时间校准。刷新波形由实际改动决定：小变化快速刷新，大变化全刷，并在整点清除残影。

## 删除与恢复屏幕

屏幕列表右侧的垃圾桶按钮用于删除，弹窗显示名称和蓝牙地址，避免同名屏幕删错。删除后停止同步并记住被删除的设备，自动发现不会立即将其加回；屏幕已收到的画面保留。需要时，在“发现屏幕 → 已删除的屏幕”中恢复设备及原画布。删除记忆和独立同步间隔都保存在持久化数据目录中。

## HA 连接

“设置”中填写 Base URL 和长期访问令牌，点击“保存并连接”。输入框立即清空，页面只显示是否已配置，不能查看保存的 Key。之后留空 Key 只修改地址并保留现有 Key。Docker 中配置写入 /data/ha-connection.json；部署时必须持久化 /data。备份该目录时也要将其作为私有凭据保管。

## 固件与批量升级

“固件”页面上传 ESP32-S3 应用 .bin 或 DA14585 SUOTA .img，勾选目标后开始升级。一个网关上的目标依次升级，多个网关可以独立处理。升级需要支持 SUOTA 的基础固件已在 Flash 中运行，ROM 引导程序自身不会提供蓝牙烧录服务。

初装 DA14585 时，本机 SDK6 构建命令为：

```sh
uv run python scripts/build_tag.py --suota --work .local/tag-suota
```

输出 build/tag.img 用于以后网页升级，build/tag-factory.bin 包含本地官方引导程序和首次镜像，用于首次有线安装。SDK 和官方引导程序仅在本机使用，不包含在群晖镜像中。项目不写入 OTP。

墨水屏 0.3.2 使用 SDK6 的 `default_app_generate_unique_static_random_addr`，读取芯片出厂 OTP 数据生成地址。同一个首次安装 BIN 可用于多块屏幕，正常出厂数据不同的芯片会有不同地址；同一块重启和升级后保持地址。旧版构建把本机测试板的地址写入镜像，多块使用会被合并。已有重复地址的屏幕需要逐块有线重装，然后重新发现与配置；详细步骤见 [屏幕身份与烧录](tag-device-identity.md)。

scripts/install_tag.py 是面向已确认空白 FM25Q04 的首次安装工具，必须先读取、核对并保存完整的 512KB Flash 备份，再用 --suota --probe-flash --install-flash 构建和加载 RAM 编程器。工具只允许逐扇区编程、读回核对，并在最后提交产品头；不能用它直接覆盖已有非空 Flash。

接收端升级仅写入当前运行镜像以外的分区，完成全部数据并核对 CRC 后标记镜像有效。网关发出重启命令后重新连接读取镜像 CRC；MCU 在重启前未回复最后一条 ATT 写请求时，也必须完成这个身份核对才能显示升级完成。

0.3.1 是 A41 的屏幕驱动补丁，只缩短已确认 70 字节 LUT 配置的快速驱动波形；全刷条件和其他型号的波形参数保持原样。已有 0.3.0 网关和工作台可直接下发，不必重新部署 Docker。单独的 OTA 包包含旧版回退镜像，详细依据见 [屏幕固件分析](panel-firmware-analysis.md)。
