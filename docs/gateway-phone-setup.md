# ESP32-S3 手机配网

网关 0.3.2 内置配网页面，不依赖外部网站或 HA。首次未配置时开启 `epapers-xxxxxx` 热点，后缀为网关 MAC 的最后六位。热点为开放网络，手机连接不需要密码。`EP_SETUP` 消息仅提供热点名称与页面地址。

1. 给网关上电，手机连接其配网热点。手机提示“没有互联网”时选择继续使用该 Wi-Fi。
2. 连接后手机会进行联网检测，网关将检测请求重定向到配网页面。若系统显示“登录此 Wi-Fi 网络”，点击该提示；未自动弹出时，浏览器访问 `http://192.168.4.1`。
3. 扫描并选择家中的 2.4GHz Wi-Fi，也可以手动填写隐藏网络名称。填写 Wi-Fi 密码；只有实际无密码的网络才勾选“这是无密码网络”。
4. 填写工作台的服务器地址，如 `http://10.0.0.10:8099`。应使用运行工作台的电脑或群晖的局域网地址，不能填写手机或网关自身的 `localhost`。支持 HTTP、HTTPS、WS、WSS、带端口的 IP/域名，以及反向代理路径；`/ws/gateway` 自动补全。
5. 填写工作台 `.env` 中的 `EPAPERS_GATEWAY_TOKEN`。这里使用的是网关 Token，与网页访问用的 `EPAPERS_API_TOKEN`、HA 长期访问令牌不同。
6. 点击“保存并连接”。配置写入 NVS，约 3 秒后网关重启；如手机断开热点，重新连接同名热点查看结果。热点仍不需要密码。
7. 页面分别显示 Wi-Fi 与工作台连接状态。显示“已连接工作台”并持续连接 60 秒后，配网热点和 HTTP 服务自动关闭。手机切回家中 Wi-Fi，打开工作台查看网关和墨水屏。

Wi-Fi 密码和网关 Token 在保存后清空输入框，状态接口只返回是否已配置，不能读取已有凭据。修改服务器地址时 Token 留空保留原值；保留同一个 Wi-Fi 时密码留空保留原值。换到另一个 Wi-Fi 需要填写新密码。扫描结果按信号显示，只使用 ESP32-S3 支持的 2.4GHz 网络。

## 重新配网

- 网关运行期间长按 BOOT 键至少 3 秒，重新开启热点；不要按住 BOOT 键上电，否则会进入芯片下载模式。
- 配置过的网关会自动重连 Wi-Fi 和工作台；持续 60 秒无法连接工作台时自动开启配网热点，便于修改密码、地址或 Token。
- USB 控制台可发送一行 `{"type":"setup_request"}`，末尾带换行，打开热点并读取本地 `EP_SETUP` 信息。`{"type":"network_status_request"}` 返回连接状态、SSID 和 IP，不返回凭据。
- 网页 OTA 和普通固件烧录保留 NVS；不要执行擦除整个 Flash，除非需要清除全部配置。

配网页面只绑定热点网络接口，关闭热点后不能从家庭局域网读取配置。网关等待热点网络接口就绪后再启动 HTTP；0.3.1 的启动竞争会误绑定到回环接口，导致热点可连接、网页却拒绝连接，已在 0.3.2 修复。

热点提供本地 DNS，Android、Apple、Windows 等常见联网检测路径返回带内容的 HTTP 302，并统一跳转到 `http://192.168.4.1/`；支持 GET 与 HEAD。DHCP 同时广播 Option 114，指向返回配网页面地址的 `/captive-portal` JSON 接口。各系统对自动弹窗、明文 Captive Portal API 的支持有差异，传统 DNS / HTTP 检测仍作为主要入口。升级后需断开再重新连接热点，重新获取 DHCP 信息并触发检测；若手机缓存了检测结果，可忘记该热点后重连。手动入口始终为上述 HTTP 地址。

设置中的服务器地址应可从家中 Wi-Fi 访问；若使用 HTTPS/WSS，需要有效的服务器证书。

## 连接诊断

`network_status_request` 与网页 `/api/status` 增加以下无凭据诊断字段：

- `setup_http_ready` / `setup_dns_ready`：网页与 DNS 服务就绪状态。
- `setup_http_interface` / `setup_ap_interface`：网页绑定接口与实际热点接口，应相同，且为 `ap...`。
- `setup_clients`：当前连接热点的设备数。
- `setup_page_requests` / `setup_redirects` / `setup_dns_queries`：页面访问、联网检测重定向及 DNS 查询次数，便于判断手机是否实际访问了网关。

## 构建和首次安装

`sh scripts/build_gateway.sh` 使用本机 ESP-IDF 构建。网页源文件位于 `firmware/gateway/main/setup.html`，在编译时嵌入应用，所有样式与脚本均离线可用。`build/epapers_gateway.bin` 是网页 OTA 使用的应用文件，不包含启动程序和分区表；首次 USB 烧录应使用 ESP-IDF 生成的完整 flash 参数。

当前验证：ESP32-S3 原生 USB 烧录及读回摘要校验、0.3.2 的 HTTP 与 DNS 就绪，以及网页绑定接口与实际热点接口相同；183 项主机测试通过（其中 28 项测试直接调用配置解析的 C 代码、34 项测试直接调用 Captive Portal 的 C 代码）、1 项跳过。配置表单的手机与桌面浏览器验证使用本机 QA 服务与真实 C 配置解析，Wi-Fi 连接与 NVS 在该 QA 服务中模拟；真实手机自动弹窗与家庭 Wi-Fi 的端到端结果需以设备和手机连接状态为准。
