# 实施与实机验证记录

工作台在本机 `http://127.0.0.1:8099` 运行，后续放在群晖 Docker。HA 通过 API 提供实体与历史记录；配套轻量集成读取屏幕状态、同步名称与房间。渲染与字体不放入 HA。

## 当前可用

- ESP32-S3 蓝牙自动发现、USB 联调桥接、重连、任务确认、网页 OTA（重启后镜像标识核对已通过）。
- DA14585 本地时钟、日期、倒计时、屏幕温度、最多 6 个画布；轮播间隔为整数分钟，离线继续运行。画布和动态字形总和上限 16KB。
- 组件轮播：固定画布内仅替换一个区域的标签与数值，最多 8 个 HA 实体，每项停留 1–1440 分钟。实体列表可排序、命名和逐项预览，画布可保存为复用模板。断线后 MCU 继续切换已下载的读数；HA 新读数按屏幕合并更新间隔下发。标签、时钟和日期共用最多四个本地动态区域。
- 设置页面可保存 HA Base URL 和 API Key。保存后 Key 输入框清空，任何读取接口仅返回“已配置”；留空保留现有 Key。私有文件以 0600 权限原子写入持久化数据目录，Key 不放入页面配置和 SQLite。
- 8 种字体，含圆润字体、中文、数字字体与字重。输出为确定的黑白像素，不使用照片式抖动。
- HA 历史趋势：时长以 15 分钟调整，时间网格 15 分钟，数值标注、空缺断线；实体可按领域、类别、房间、设备筛选。
- 屏幕和网关名称、房间持久化；用户画布可保存为模板并适配其他屏幕尺寸。
- HA 集成提供屏幕温度、供电电压、电量、信号、刷新次数和操作按钮。名称、实体 ID 前缀和房间同步只修改本集成拥有的设备与实体。

## 花屏修复（2026-10-06）

实物为 LUT 长度 70、引脚组 6 的 A41 配置。控制器断电后会丢失内部 RAM；只写变化窗口后执行快速波形会使窗口外像素不确定。现在每次有像素变化都先写入完整 RAM，然后根据变化规模选择波形；补齐参考驱动的电压、帧率和 LUT 相位参数。

- 小幅变化：C7 快速波形。
- 首次、手动、尺寸/方向变化、整点或距上次全刷一小时：F7 全刷。
- 变化的 8×32 像素块覆盖面积达到屏幕 25%：全刷。此阈值按变化块保守计算。
- 相同画面：跳过画面刷新；温度采样单独按 10 分钟缓存。

这属于全 RAM 写入后的快速刷新，目前没有启用裁剪 RAM 窗口。SPI 控制器模拟测试验证断电丢失 RAM、小变化、无变化、大变化、手动和整点刷新；用户已确认 15:25 修正后的实际画面正常；随后确认温湿度/时间与屏幕自身温度两画布按分钟轮换均正常。实机诊断已上报 9 次全刷、1 次快速刷新，最近全刷原因为大幅画面变化。MCU 完成回执只确认流程完成，不能判定物理画面质量。

## 硬件与未完成验证

- 当前板的 SPI Flash 实际为 FM25Q04（JEDEC A14013，512KB）；通过 MCU 的实际 SPI 接口完整备份并验证全 FF。已读取到原有 OTP 引导标识 1234A5A5，没有写入 OTP。
- SDK6 SUOTA 基础固件已写入 Flash，逐扇区读回一致；重启后已核对运行固件 CRC。双镜像地址 0x4000 / 0x1F000，产品头 0x38000。接收端只接受固定 Flash 引脚和自动备用分区，先核对长度、向量和完整 CRC，最后设置有效标记。Flash 未识别或运行镜像身份未核对时不宣称支持无线升级。
- 当前电源为 J-Link，用户测量 3.267V；ADC 约 3.286V。供电电压不能自动当成电池原电压，当前电量百分比为空。
- A55/OPM 在协议、渲染与主机测试中支持，尚未完成对应实物屏幕验证。
- 网关和屏幕的组件轮播需要固件 0.3.0。RAM 诊断版本仍不支持无线升级；网页批量升级按每个网关串行执行，以重启后镜像身份核对为完成条件。断电中断、损坏镜像引导回退与长期稳定性尚未做完整实机验证。
- 200mAh 电池续航与睡眠电流尚未实测。当前使用分钟对齐计时、扩展睡眠、10 分钟传感器缓存、网关 15 分钟空闲状态轮询，默认实体变动合并至 5 分钟更新。
- HA 集成已在 Home Assistant 2026.9.4 的真实注册表/API 环境测试；尚未安装到用户的 HA 主机。

参考项目：[HMCLOCK](https://github.com/tpunix/HMCLOCK)。官方 SDK6 仅在本机使用，不打包其源码与库。

0.3.1 的 A41 快速路径随后参考用户提供的 V26 / B25 固件改为 10 帧短波形，完整 RAM 写入及全刷选择策略保持原样。分析依据、寄存器差异、测试与 OTA 身份见 [屏幕固件分析](panel-firmware-analysis.md)。A55 / OPM 快速参数没有更改。

Docker `linux/amd64` 镜像在只读根文件系统、512MB 限制下完成 8 种字体的 27 个字重组合渲染和 HA 插件下载验证。0.3.0 镜像另已验证 HA 私有配置保存、0600 权限、读取不回显 Key 与组件轮播渲染，cgroup 测得本次测试峰值约 133.7MiB，无 OOM。镜像不包含 `.env`、`.local`、SDK 或本机用户数据。
