# V26 / B25 屏幕驱动分析与第一版 OTA

## 输入与校验

只读分析用户提供的两个二进制，不将其写入设备，也不将原固件打包分发。以下代码地址为加载到 0x07FC0000 后的 Thumb 地址；第一镜像的文件偏移为 0x2040。

| 文件 | 文件 SHA256 | 主镜像长度 / CRC |
|---|---|---|
| bw213_V26L00.bin | a69ff13ff6ab2c4356ab295ce46c28114987b8cc77fddc0fe1de3944e1c81868 | 0x10CB4 / 7ED7052E |
| HM213_B25L01.bin | bc3efa12044991004f62ed37ca057d403e1a0f2ab38201c671bf39f7d4f51520 | 0x10C20 / A502A782 |

两个文件长度均为 0x38018，产品头指向 0x2000 / 0x14000 两个分区。两个主镜像的 CRC 实算均与头部一致。备用镜像相同，长度 0xC4F0、CRC ECA9D137，不能把其中内容误认为 V26 / B25 的主驱动差异。

使用 ARM objdump 与 Capstone 静态反汇编，另以 Unicorn 执行已定位的初始化及刷新函数。只将 SPI 命令/数据、传感器读取、GPIO 配置、等待、日志和定时回调替换为本机桩；不执行真实 GPIO。模拟传感器为 26°C。寄存器轨迹保存在本机 .local/firmware-analysis 下，模拟并不等于物理显示测试。

## 有明确证据的差异

| 路径 | V26 | B25 |
|---|---|---|
| 初始化函数 | 0x07FC1F94 | 0x07FC1F40 |
| 刷新函数 | 0x07FC4B04 | 0x07FC4A6C |
| 快速波形来源 | 主动写入 70 字节 LUT | 从控制器 OTP 加载 |
| RAM24 | 写入当前图像 | 写入当前图像 |
| RAM26 | 写入 RAM24 的反相图像 | 写零 |
| 快速模式末尾 | 22=0C，20 激活；初始化先 22=C0 | 22=CF，20 激活 |

V26 快速 LUT 位于主镜像偏移 0xAA94（整个文件偏移 0xCAD4）；完整快速清理 LUT 位于 0xAA48。前者四条像素 LUT 的第一阶段分别是 00 / 80 / 40 / 00，其余像素阶段为零；TP0A=0A，所有 RP=00，即只驱动 10 帧。初始化中可确认 Gate=15、Source=41 A8 32、VCOM=28、Dummy line=30、Gate line width=0A。

B25 快速模式可确认额外写入 1A=5A 00，再通过 22=91 加载 OTP，最后用 CF 更新。它没有与 V26 相同的应用内短 LUT；不能从该文件直接得到其控制器 OTP 内的全部波形。

V26 刷新循环可确认原生 RAM 每行 16 字节、共 250 行；两份完整数据分别在 0x07FC4D72 和 0x07FC4D9C 开始写入。该几何和模式选择没有直接移植到当前 104×212 的 A41 配置。V26 的短波形与电压参数是本次参考范围，不复制其 37 寄存器的保留位设置、模式 0C 或上电期间保持模拟电路开启的流程。

## 有限的改动

只在 panel_model=1、LUT 长度 70 的 A41 快速刷新路径启用短波形；A55 和 OPM 保留原参数。

IL3897 的 LUT 选择由辅助 RAM 和黑白 RAM 的两位组合决定。V26 将辅助 RAM 写成黑白 RAM 的反相，因此黑像素选择 LUT2=40，白像素选择 LUT1=80。新驱动将 LUT2 复制到 LUT0、LUT1 复制到 LUT3：无论辅助 RAM 的位为 0 还是 1，实际黑白驱动阶段都与 V26 对应的输出一致。这允许继续只写一份完整黑白 RAM，不依赖断电后辅助 RAM 的内容，也不增加第二份 SPI 图像传输。

短波形采用 TP0A=10、RP=0、VCOM=28、Dummy line=30、Gate line width=0A。旧快速波形是 TP0A=15、RP=1，按资料中的 RP+1 规则共 30 帧。驱动帧数降至三分之一；SPI、初始化、关断仍有开销，所以不能将此直接写成“整体快 3 倍”或“续航增加 3 倍”。VCOM、帧参数以用户已验证能用的 V26 为依据，显示质量仍须实物确认。

刷新选择策略保持原样：无变化跳过；小变化快速；首次、失败恢复、手动、大变化、整点或距上次全刷一小时使用控制器 OTP 全刷。继续完整重写黑白 RAM；用现有 C7 序列在完成显示后关闭模拟电路和时钟，随后深睡并切断板上屏幕电源。不写入 MCU 或屏幕 OTP。
